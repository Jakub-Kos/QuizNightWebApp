# How to use Quiz Night OS

[English](USAGE.md) · [Čeština](USAGE.cs.md) · [Slovenčina](USAGE.sk.md)

Quiz Night OS runs in the browser. Open the [app](https://jakub-kos.github.io/QuizNightWebApp/); there is
nothing to install and no account. Your quizzes are saved in the browser you made them in, so export a
quiz as a `.zip` to back it up or move it to another computer. Use Chrome or Edge.

## 1. Make a quiz

Start in the **quiz library**. Click **New quiz**, or open the built-in demo to look around first.
The quiz setup page has a checklist at the top that shows what is still missing.

| Section                | What to do                                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------------------------- |
| **Look**               | Pick Classic, Halloween or Christmas, import a theme, or open the theme editor.                      |
| **Questions**          | Write them in the app's questions editor, or link a Google Sheet (below).                            |
| **Pictures and media** | Drag in the pictures, sounds and videos your questions name. A whole folder works.                   |
| **Teams**              | Type them in, import a CSV, or load the names from the scores Sheet. Photos and mottos are optional. |
| **Scores**             | Link a scores Sheet, or type the points into the app during the night.                               |
| **Rules and prizes**   | Edit the rules and prizes screens, or switch either screen off.                                      |

### Questions from a Google Sheet

1. Copy the Sheet template (Help → Templates) and fill it in.
2. Share the Sheet as _anyone with the link can view_.
3. Paste the link into the Questions section.

Help → Question types shows the exact rows for each type and how it looks on the TV. The types are:
multiple choice, yes or no, number, written answer, top list, put in order, printed handout, with a
picture, picture first, with a sound, with a video, and video first.

### Check before the night

- **Check** shows every question as the TV will show it, with a list of what is missing or wrong.
- **Map** shows every screen of the evening in order and what moves you to the next one.

## 2. Run the night

1. Connect the laptop to the TV. Open the quiz and click **Start show**.
2. Drag the show window to the TV and press `F11` for full screen.
3. Press `Shift + P`. The host window opens; keep it on the laptop.
4. If the TV cuts off the edges, press `Shift + C` in the TV window and shrink the picture.

The TV follows every click in the host window. Both windows must be in the same browser on the same computer.

### The order of the evening

1. **Welcome**: each team gets an introduction.
2. **Rules**, then **Prizes** (if switched on).
3. **Rounds dashboard**: the centre of the night. Every round, the leaderboard and the break start here
   and come back here.
4. **A round**: play it with answers, or questions only and reveal the answers later.
5. **Leaderboard**: reveal the round's points group by group, from the lowest score up.
6. **Break**: a countdown with the teams and the live standings.

### Keys

| Key         | Does                                           |
| ----------- | ---------------------------------------------- |
| `→` / `←`   | Next / previous step                           |
| `Shift + P` | Open the host window                           |
| `Shift + D` | Jump back to the rounds dashboard              |
| `Shift + C` | Adjust the picture size for the TV             |
| `Z`         | Enlarge the question's picture                 |
| `Esc`       | Close the picture, or leave the current screen |

### Attendance and scores

- **Attendance**: before you start, tick the teams that came, fix the number of players, and place each
  team on the map of the room. During the leaderboard reveal the host window shows which way to look.
- **Scores**: type each team's points for each round. They save at once and the leaderboard in the
  running show updates by itself. With a linked scores Sheet, the show reads the Sheet instead.

## 3. Themes

Each quiz picks its look in the setup page. The **theme editor** changes colours, fonts, the background
picture, glows, scenery and decorations, with a live preview of every screen and a readability check.
A theme can be exported, imported, and saved to **My themes** for other quizzes.

The **theme workshop** (linked from the library) shows themes other hosts shared. To share your own,
click **Share to the workshop** in the theme editor; it appears after review.

## 4. Settings and language

The gear icon in the show opens the settings: language, sounds and volume, animation speed and the
start time. The app is in English, Czech and Slovak.

## Good to know

- Quizzes live in one browser on one computer. Clearing the browser's site data deletes them. Export a `.zip`.
- A linked Google Sheet needs the internet. Questions written in the app and media you dragged in do not.
- Editing a linked Google Sheet is done in Google Sheets; the app only reads it.
